# FaceDetect Pro
# Normal project 
AI-powered full-stack face detection application built with **React.js, Node.js, Express.js, MongoDB, and face-api.js**.

## Features

- Real-time face detection
- Camera and image upload
- Face count & confidence score
- Detection history
- Dashboard & statistics
- MongoDB database
- REST API

## Tech Stack

**Frontend:** React.js, Vite, face-api.js, Axios  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose

### Frontend
